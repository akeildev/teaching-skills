# Existing concept lists and fixed outlines

- **Existing concept list:** leave it unchanged. Build the outline as a separate file that links each original record to its place. Put new records in a separate addendum file with new IDs and a version note.
- **Outline the user says is fixed:** keep it as it is and check it. Report suggested changes separately, each with old-to-new ID mappings and a reason.
- **Revising an earlier outline:** record what happened to each old unit ID (kept, merged, split or retired) in `unit_migrations`. A retired ID is never reused.
