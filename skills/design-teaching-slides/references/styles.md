# The user's styles

Every style lives in one of two Paper files. Each row is one slide kind and each column one style; artboard names give both.

- **Teaching Mode List | External** (`01M6CNCK8VSPENSB695BM3KAK4`, page `p-3-1` "Final List #1"): ten styles. The file is at Paper's size limit, so read from it only.
- **Teaching Mode List | Basics** (`01M6CN004P49D2KT6TFPJZ6BY0`, page `p-1-0`): Daylight, Night, Glowline, Watercolor and Sketch. The file's design tokens hold their palette and fonts.
