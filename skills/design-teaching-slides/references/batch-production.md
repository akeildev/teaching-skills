# Large and resumed decks

- **One brief, one tracker.** The tracker lists each lesson or slide group with its artboard IDs and status (pending, built, checked, approved, blocked), and records replaced slides so they aren't mistaken for current ones.
- **Resuming:** compare the tracker with the destination first, and inspect partial work before redoing it.
- **Batches:** group by lesson or style, small enough that a mistake is caught before it spreads.
- **Parallel builders:** give each separate slides and the same brief; each keeps the others' work intact. A builder's report is not evidence: screenshot a sample from every batch and every high-risk slide (numbers, diagram meaning, question reveals).
- **Interruptions:** find out what finished before redoing anything. Tell access, coordination and rendering failures apart before retrying.
- **Unreachable destination:** report it and keep the local work; the deck is not delivered.
