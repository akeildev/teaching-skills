# Teaching skills

Agent Skills that turn a source into a finished teaching slide deck.

1. `organize-teachable-concepts` builds an evidence-linked outline: the main point, families, teaching units, components and supporting material.
2. `plan-teaching-modes` chooses the teaching modes for each unit and arranges the units into timed lessons.
3. `design-teaching-slides` builds the deck in one of the user's illustrated styles, writing the lesson's wording, questions and pictures.
4. `basics-create` runs the three in order on an uploaded document (invoked by name).

Each skill needs only the Python standard library for its scripts.

## Install

Copy or link each folder in `skills/` into your agent's skills directory, such as `~/.codex/skills/` or `~/.claude/skills/`.
