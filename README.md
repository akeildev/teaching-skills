# Teaching skills

Two Agent Skills that turn a source into a course plan.

1. `organize-teachable-concepts` builds an evidence-linked inventory: families, teaching units, components, and supporting material.
2. `plan-teaching-modes` designs how to teach those units for a specific learner, with exercises and animated-scene beats paired with narration.

Each skill needs only the Python standard library for its scripts.

## Install

Copy or link each folder in `skills/` into your agent's skills directory, such as `~/.codex/skills/` or `~/.claude/skills/`.
